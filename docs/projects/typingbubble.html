Typing Bubbles Mod Documentation

Typing Bubbles Community Mod

  • Typing Bubbles is a simple mod providing a simple notification for when a player is typing. A typing bubble will appear over their head signifying that they are typing. Server admins have the option to configure the distance that other players can see this typing bubble, but that is not required.

INI Settings

To see all available INI options, please head over to: INI Settings

Configuration

  • We recommend you utilize Mod Menu for easy, in-game configuration. However, Chat Bubbles does also support ini-based configuration, for when Mod Menu is not installed.
